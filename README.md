# REEL project page

This repository hosts the public project page for **REEL: Same Frames,
Different Answers and Different Costs**, accepted at WACV 2027 in the
Datasets & Evaluation Track.

Website: <https://liangxin1001.github.io/REEL/>

The current page is an early public version. The public paper, camera-ready
author metadata, final citation, and audited code link will be added when they
are ready. The confidential review manuscript is intentionally not included.

## Local preview

Run a static file server from the repository root, for example:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

The paper figures and manuscript remain copyright their respective authors.
