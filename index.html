The question behind REEL

What should a long-video system save?

When one video must answer many later questions, the saved representation should reduce repeated work without silently changing the answers.

01 · THE HIDDEN CHANGE

A stable mean can hide a different set of correct answers.

Text and Frames can report nearly the same average accuracy while disagreeing on which individual questions are correct. Gains and losses cancel in the mean.

21.1–29.6% of jointly valid questions change correctness between Text and Frames across the tested model–dataset pairs.

Visual and Prefix stay much closer to Frames: 0.0–2.3% and 0.3–2.8% differing outcomes, respectively.

03 · WHAT REUSE REALLY SAVES

Compute, storage, and answer fidelity pull in different directions.

01

Kilobytes

Text is tiny—but lossy.

Text stores roughly 6.1–8.6 KiB per video, but fails the paper's answer-retention rule on the main workloads.

02

1.06–20.97 GiB

Prefix saves GPU work—not space.

Once answer retention is required, Prefix State is the lowest-GPU eligible choice in every tested main workload.

03

Model-specific

Where the saving comes from changes.

Skipping vision encoding and reusing language-model prefill contribute very different shares across model families.

04 · SELECT ONCE OR SELECT PER QUESTION?

Question-aware selection is not automatically better.

Selecting frames separately for every question helps on CG-Bench, but not on HD-EPIC—and it repeats selection work each time. REEL therefore evaluates evidence selection separately from memory representation.

+6.2–7.6 ppCG-Bench accuracy
−0.1–1.5 ppHD-EPIC accuracy
1.63–5.59×total GPU time

05 · THE REEL CHECKLIST

Measure reuse with three ledgers, not one headline score.

  1. 1
    Fix the observations.

    Use exactly the same selected frames for every representation.

  2. 2
    Pair every answer.

    Count correct→wrong and wrong→correct changes, not just mean accuracy.

  3. 3
    Track cumulative GPU work.

    Include construction and every later question as the workload grows.

  4. 4
    Count retained bytes.

    Separate computation saved from information stored.

SCOPE

What the result does—and does not—claim.

Supported

Under the tested models, datasets, frame budgets, and retention checks, Prefix State is the lowest-GPU eligible saved representation.

Not universal

Different hardware, writers, storage limits, question mixes, or compression methods can change the ranking.

Why REEL matters

The framework makes those conditional trade-offs visible instead of hiding them behind a single average.
