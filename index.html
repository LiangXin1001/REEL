The question behind REEL

What should a long-video system save?

When one video must answer many later questions, the saved representation should reduce repeated work without silently changing the answers. In the example below, all four paths see the video file, but the Text record drops its type—so the later answer changes.

01 · THE HIDDEN CHANGE

A stable mean can hide a different set of correct answers.

Text and Frames can report nearly the same average accuracy while disagreeing on which individual questions are correct. Gains and losses cancel in the mean.

19.7–28.7% of jointly valid questions change correctness between Text and Frames across the tested model–dataset pairs.

Visual and Prefix stay much closer to Frames: 0.0–1.9% and 0.3–1.8% differing outcomes, respectively.

PAIRED ANSWER CHANGES

Losses and gains can cancel in the mean.

Each red point shows the share of questions that Frames gets right and Text gets wrong; each blue point shows the reverse. Both directions remain large even when the yellow net-accuracy marker sits close to zero.

WHAT THE QUESTION ASKS

The changes depend on question type.

On HD-EPIC, Text consistently hurts questions about object contents and helps questions about movement across all six backbones. The pattern is different on CG-Bench, so one average cannot describe which information the representation preserves.

03 · WHAT REUSE REALLY SAVES

Compute, storage, and answer fidelity pull in different directions.

01

Kilobytes

Text is tiny—but lossy.

Among the three storage-profiled backbones, Text stores roughly 7.2–9.7 KiB per video, but fails the paper's answer-retention rule.

02

1.06–20.97 GiB

Prefix saves GPU work—not space.

Among the three storage-profiled backbones, Prefix State retains 1.06–20.97 GiB per video. At Uniform-64, over the evaluated horizons and without a storage cap, it is the lowest-GPU eligible choice in all 12 workloads.

03

Model-specific

Where the saving comes from changes.

Skipping vision encoding and reusing language-model prefill contribute very different shares across model families.

QUALITY CHANGES THE WINNER

Compute alone selects the wrong memory in half the workloads.

At Uniform-64, GPU time alone selects Text in six model–dataset pairs and Prefix State in six. Over the evaluated horizons, after both answer-retention checks and without a storage cap, Prefix State is selected in all twelve.

TWO DIFFERENT COSTS

Storage and repeated GPU work are separate axes.

Text keeps only kilobytes but changes many answers. Prefix State retains far more bytes, yet avoids more work as questions accumulate. Construction cost and per-question cost must therefore be counted together.

WORKLOAD MATTERS

The same representation occupies a different trade-off point in each workload.

The CG-Bench endpoint contains six questions per video; HD-EPIC contains many more. Position shows retained bytes and GPU saving, while color shows the accuracy change against Frames.

04 · SELECT ONCE OR SELECT PER QUESTION?

Question-aware selection is not automatically better.

In the Qwen3-VL-8B sweep over 32, 64, and 128 frames, selecting frames separately for every question helps on CG-Bench, but not on HD-EPIC—and it repeats selection work each time. REEL therefore evaluates evidence selection separately from memory representation.

05 · THE REEL CHECKLIST

Measure reuse with three ledgers, not one headline score.

  1. 1
    Fix the observations.

    Use exactly the same selected frames for every representation.

  2. 2
    Pair every answer.

    Count correct→wrong and wrong→correct changes, not just mean accuracy.

  3. 3
    Track cumulative GPU work.

    Include construction and every later question as the workload grows.

  4. 4
    Count retained bytes.

    Separate computation saved from information stored.
